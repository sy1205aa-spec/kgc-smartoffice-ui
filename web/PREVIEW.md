# PC 웹 현업 검토 시안

- 시작 화면: `web/index.html`
- 메인 시안: `web/main.html`
- 2026-10-20 퍼블리싱의 CSS·아이콘·폰트를 반영했습니다.
- 대시보드: 이용중 / 회의 4건(표시는 최대 2건) / 미예약 상태를 선택합니다.
- 주차: 차량 조회 → 상세 → 할인권 등록·취소를 시연합니다.
- 셔틀: 노선 선택 → 예약 → 취소를 시연합니다.
- 공통 헤더: 대시보드, 주차, 셔틀, 기존 공간예약 스냅샷에 동일 적용됩니다.
- 통합 메뉴 변경: 검토 허브 하단에서 메뉴명·노출 여부를 변경합니다.

이 시안은 예시 데이터로 동작하며 NETS SSO, 운영 DB, 실제 예약·결제, 원격 메뉴 API에는 연결하지 않습니다. 기존 공간예약 화면은 정적 스냅샷으로 업무 기능 일부는 동작하지 않습니다. 앱 QR은 설치 URL 확정 전이므로 준비중으로 표시합니다.

## 로컬 확인

저장소 루트에서 `python -m http.server 8080`을 실행하고 `http://localhost:8080/web/index.html`을 엽니다. 통합 메뉴 시연 설정은 출처별 localStorage에 저장되며 허브에서 초기화할 수 있습니다.
